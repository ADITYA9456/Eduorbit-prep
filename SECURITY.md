# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

- Email: `[SECURITY CONTACT EMAIL, TO BE FILLED IN BY THE OWNER]`
- Or use GitHub's "Report a vulnerability" (private advisory) on the repository, if enabled.

Include what you found, the URL or file, steps to reproduce, and the impact. Do not access other users' data beyond what is needed to show the issue, do not run denial-of-service tests, and do not test against production accounts that are not yours.

We aim to acknowledge reports within `[3 working days]` and to keep you updated until it is resolved. `[Owner to confirm these targets.]` We do not currently offer a bug bounty.

## Scope

This repository (EduOrbit Prep): the web app, its API routes and database migrations. Third-party services (Google, Supabase, hosting provider, Anthropic) should be reported to those vendors.

## Supported versions

Only the latest deployed version of the `main` branch is supported.
